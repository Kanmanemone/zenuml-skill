## User Scenarios & Testing *(mandatory)*

### User Story 1 - 변환 중에 터미널 창이 뜨지 않기 (Priority: P1)

Windows에서 다이어그램이나 문서를 변환하면, 지금은 변환 한 번에 터미널 창이 두 번 떴다 사라진다. 작업 중인 화면 위로 창이 튀어나와 포커스를 빼앗고 거슬린다. 사용자는 변환이 화면에 아무 창도 띄우지 않고 조용히 끝나기를 원한다.

**Why this priority**: 사용자가 직접 요청한 유일한 개선이며, 변환할 때마다 반복되는 방해 요소다.

**Independent Test**: 새로 뜨는 최상위 창을 감시하는 도구를 켠 채로 다이어그램 PNG 변환과 문서 전체 PDF 변환을 각각 실행해, 새 창이 0개인지 확인한다.

**Acceptance Scenarios**:

1. **Given** Windows 환경, **When** 다이어그램을 SVG/PNG/PDF 중 어느 형식으로든 변환하면, **Then** 변환 동안 새 터미널 창(또는 어떤 새 최상위 창도)이 화면에 나타나지 않는다.
2. **Given** Windows 환경, **When** 문서 전체를 어느 페이지 구성으로든 PDF로 변환하면, **Then** 새 창이 나타나지 않는다.
3. **Given** 같은 입력, **When** 변경 전과 후에 각각 변환하면, **Then** SVG 산출물은 바이트 단위로 같다.

---

### Edge Cases

- 글자 폭에 영향을 주는 글꼴 선택이 바뀌면 다이어그램 배치가 달라질 수 있다 — 산출물이 변경 전과 같아야 한다(SVG 바이트 동일로 확인).
- 잘림 보정(005)의 측정과 최종 렌더가 서로 다른 브라우저 설정을 쓰면 여백이 어긋날 수 있다 — 스킬이 띄우는 모든 브라우저(렌더러가 띄우는 것 포함)가 같은 설정을 써야 한다.
- Windows 이외의 OS: 창 문제는 없지만, 같은 설정을 써도 산출물이 바뀌지 않아야 한다.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: Windows에서 스킬의 어떤 변환(다이어그램 단독 SVG/PNG/PDF, 문서 전체 PDF 두 페이지 구성)도 화면에 새 창을 띄우지 않아야 한다.
- **FR-002**: 변경 후 SVG 산출물은 같은 입력에 대해 변경 전과 바이트 단위로 같아야 한다.
- **FR-003**: 스킬이 띄우는 모든 브라우저(다이어그램 렌더러가 띄우는 것과 스크립트가 직접 띄우는 것)는 하나의 공통 설정을 따라야 한다 — 설정이 한 곳에서 정의되어, 측정과 렌더가 어긋나지 않는다.
- **FR-004**: 스킬의 사용법(호출 인자, 출력 위치, 출력 이름)은 바뀌지 않아야 하며, 새 외부 의존성을 추가하지 않는다.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: Windows에서 다이어그램 PNG 변환 1회와 문서 전체 PDF 변환 1회 동안 새로 나타나는 창이 0개다(변경 전: 각 2개).
- **SC-002**: 저장소 내 다이어그램 샘플 전부와 잘림 재현 샘플에서 SVG 산출물이 변경 전과 100% 바이트 동일하다.
- **SC-003**: 변환에 걸리는 시간이 체감상 늘지 않는다(변환 1회당 증가 1초 이내).

## Assumptions

- 창이 뜨는 원인은 콘솔용 브라우저 실행파일이며, 같은 브라우저의 GUI용 실행파일은 창을 만들지 않는다(실측: 변경 전 브라우저 실행마다 창 1개, GUI 실행파일은 0개).
- GUI 실행파일은 언어 기본값이 시스템 로캘(한국어)을 따라 일반 글꼴 지정이 다른 글꼴로 풀리므로, 언어를 영어(미국)로 고정해야 기존 산출물과 같아진다(실측: 고정 시 전 샘플 바이트 동일, 미고정 시 2개 다름).
- 필요한 GUI 브라우저는 브라우저 자동화 도구 설치 시 기본으로 함께 내려받아진다(이 환경에서 확인). 별도 설치 단계를 추가하지 않는다.
- 다른 OS에도 같은 설정을 적용한다 — OS별 분기를 두지 않는 편이 단순하고, 모든 환경에서 같은 브라우저로 렌더링하게 된다.
